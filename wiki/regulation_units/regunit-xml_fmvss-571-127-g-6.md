# (g) For tests where manual brake application occurs, the subject vehicle's accelerator pedal, if not already released, i

## Statement
(g) For tests where manual brake application occurs, the subject vehicle's accelerator pedal, if not already released, is released when the headway corresponds to L 2.1 at any rate such that it is fully released within 500 ms.
