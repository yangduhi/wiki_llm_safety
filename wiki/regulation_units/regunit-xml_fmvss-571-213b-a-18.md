# (A) Install the child restraint system on the standard seat assembly, in accordance with the manufacturer's instructions

## Statement
(A) Install the child restraint system on the standard seat assembly, in accordance with the manufacturer's instructions provided with the system pursuant to S5.6.1, except that, at the agency's option, the standard lap belt is used or the lap and shoulder belt is used. If provided, a tether strap may be used, but only if the manufacturer's instructions instruct consumers to use it. Attach the school bus child restraint system in accordance with the manufacturer's instructions provided with the system pursuant to S5.6.1, e.g., the seat back mount or seat back and seat pan mount are used.
