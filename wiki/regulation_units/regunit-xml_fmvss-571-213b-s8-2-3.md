# S8.2.3 In accordance with S10, place in the child restraint system any dummy specified in S7 for testing systems for use

## Statement
S8.2.3 In accordance with S10, place in the child restraint system any dummy specified in S7 for testing systems for use by children of the heights and weights for which the system is recommended in accordance with S5.5 and S8.1.
