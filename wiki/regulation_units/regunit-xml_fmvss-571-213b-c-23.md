# (c) 12-month-old dummy (49 CFR part 572, subpart R). When used in testing under this standard, the dummy specified in 49

## Statement
(c) 12-month-old dummy (49 CFR part 572, subpart R). When used in testing under this standard, the dummy specified in 49 CFR part 572, subpart R, is clothed in a cotton-polyester based tight fitting sweatshirt with long sleeves and ankle long pants whose combined weight is not more than 0.25 kg.
