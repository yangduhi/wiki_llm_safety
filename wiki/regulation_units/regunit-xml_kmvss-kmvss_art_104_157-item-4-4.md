# 4. 4. 문경첩장치는 8,800뉴턴의 자동차길이방향의 하중과 7,200뉴턴의 자동차너비방향의 하중에 견딜 것. 이 경우 뒷문의 문경첩장치는 7,200뉴턴의 자동차수직방향의 하중에도 견딜 것
