# (C) If a statement specifying a child weight limit is required for the child restraint system installed forward-facing a

## Statement
(C) If a statement specifying a child weight limit is required for the child restraint system installed forward-facing and rear-facing pursuant to S5.5.2(l)(3)(i) and only one installation diagram is provided, then the child weight limit shall be in accordance with S5.5.2(l)(3)(i)(A) or the lesser of the child weight limits described in S5.5.2(l)(3)(i)(B) and (C).
