# (2) When using the test dummies specified in 49 CFR part 572, subpart N, P, R or T, performance tests under S6.1 are con

## Statement
(2) When using the test dummies specified in 49 CFR part 572, subpart N, P, R or T, performance tests under S6.1 are conducted at any ambient temperature from 20.6 °C to 22.2 °C and at any relative humidity from 10 percent to 70 percent.
