# 3. 3. 측면보호대의 가장 윗부분과 지상과의 간격은 950밀리미터 이상일 것. 다만, 측면보호대 가장 윗부분과 차체 바닥면과의 간격이 350밀리미터 이하일 경우는 제외한다.
