## Basis
(b) To calculate the corrected stopping distance using the actual vehicle test speed, the following formula is used:
Ss = 0.1·Vs + (Sa−0.1·Va) · Vs 2 /Va 2 ,
Where: Ss = corrected stopping distance in meters Vs = specified vehicle test speed in km/h Sa = actual stopping distance in meters Va = actual vehicle test speed in km/h
Note to S5.3.1( b ): This equation is only valid when the actual test speed (Va) is within ±5 km/h of the specified test speed (Vs).
