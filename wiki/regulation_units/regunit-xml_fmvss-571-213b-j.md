# (j) In the case of each child restraint system equipped with a tether strap system the statement: Secure the tether stra

## Statement
(j) In the case of each child restraint system equipped with a tether strap system the statement: Secure the tether strap provided with this child restraint. For child restraints manufactured before January 8, 2028, the statement may state: Secure the top anchorage strap provided with this child restraint.
