# Generated Surface Baseline

## Policy

- This contract covers only official graph surfaces under `docs/` and `wiki/indexes/`.
- Graph markdown in this contract is classified as either:
  - `tracked source doc`
  - `committed generated artifact`
  - `ignored local-only output`
- `wiki/concepts/*.md` and graph blocks injected into selected `wiki/regulation_documents/*.md` may be rewritten by the builder, but they are outside this generated-surface Git contract baseline.

## Local-Only Outputs

- No graph-specific markdown file under `docs/` or `wiki/indexes/` is treated as local-only in the current contract.
- Ignored local-only output remains limited to already ignored paths such as:
  - `artifacts/`
  - `.obsidian/workspace.json`
  - `.obsidian/workspaces.json`

## Refresh Contract

- `.\scripts\wiki.ps1 graph-refresh` is the canonical regeneration path for builder-owned official graph surfaces.
- `graph-refresh` is expected to refresh the builder-generated graph docs and graph hubs listed above.
- `graph-refresh` does not define a separate graph-only local markdown output path.

## Verify Contract

- `.\scripts\wiki.ps1 verify` runs `graph-refresh` before generated-surface checks.
- `verify` treats committed generated graph artifacts as part of the repository baseline.
- Stale generated graph surfaces are verify failures, not optional local churn.
- Manual tracked graph docs remain part of official discovery and linking, but they are not freshness-baseline artifacts.
