# Obsidian Shared Vault Pilot Note

## Purpose
- Obsidian remains a navigation and review layer over canonical repository content.
- During the ontology pilot, Obsidian should document the new classification design, but it should not be treated as proof that production runtime migration is approved.

## Pilot Position
- The image-based 16 categories are treated as `in_crash` browse taxonomy only.
- Global classification is being redesigned as a faceted ontology with `regulatory_layer`, `phase`, `functional_domain`, and `topic/object`.
- Legacy taxonomy remains a migration reference and must not be reintroduced as the global root through vault navigation decisions.

## Workspaces
- Existing workspace layout may remain stable during the pilot.
- If additional browse notes are added, keep them under `docs/operations/` until production migration is approved.
- Do not use the shared vault to silently redefine the live wiki taxonomy.
